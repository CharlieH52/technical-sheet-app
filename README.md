# What is?
Store the main information about a computer *(actually only Windows)* in a **JSON** local storage, with the posibility than upload the same information in a **Google Sheet** like a *Data Base* using an API.

You can share that sheet with your admin partners for the consult and manage the computers information in your network.

## Requirements
* Psutil
* Pyinstaller
* Regex

## Configuration
> [!IMPORTANT] 
> You can change in the *main.py* file the constant value of **SHEET_FUNCTION** to False, if you don't need these feature.
